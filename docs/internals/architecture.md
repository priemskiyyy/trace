# Runtime architecture

Trace guarantees how an event is declared, validated, sanitized, given its identity, routed, gated by consent and handed to each destination. It claims nothing about what a provider does afterwards beyond the evidence its adapter gives. This page describes the parts that keep that guarantee and names the test that guards each rule. Test files live in `packages/core/src` unless another package is named.

## Owners

Every piece of state has one owner, and only the first two rows below are exported.

| Owner                                       | Responsibility                                                                                                                                                                |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Trace`                                     | The facade. Reads the options once, runs the intake of an event, routes it, owns the receipts and the `events` stream, and tells every lane when identity or consent changes. |
| `createMockAdapter`, `testAnalyticsAdapter` | The deliberately badly behaved test double, and the contract every adapter keeps.                                                                                             |
| `IdentityState`                             | The identity target: the generation, the user, the traits and the group memberships, with a `null` tombstone for each removal.                                                |
| `planIdentity`                              | The pure planner: the ordered identity steps one session needs before it holds a given identity.                                                                              |
| `ConsentState`                              | The decision for each purpose, and whether each destination is open. It fails closed.                                                                                         |
| `DestinationLane`                           | One destination: its session, the bounded `LaneBuffer`, the identity it last applied, each handoff and its deadline, flush and disposal.                                      |
| `Diagnostics`                               | The passive snapshot and the timeline of payload-free diagnostic events.                                                                                                      |

Intake is separate from the lanes. `readOptions` resolves every option once, at construction, and an option that cannot work throws there. `parseEvent` validates the properties with the event's definition, and `prepareEvent` composes the context layers with `composeContext` and sanitizes the properties and the context with `sanitizeValue`. `prepareLayer` prepares traits, group traits and `trace.context()` when they are set: it validates each key against the schema, sanitizes the values, and withholds the removal of a key that `redact` names, so that key never reaches a provider. `boundLayer` then bounds the traits a user or a group has accumulated across calls by the same limits. A loss belongs to exactly the key that caused it and rides on every receipt that key would have ridden. `createReceipt` owns one receipt, which settles exactly once. `getTrackOutcome` and `getFlushResult` copy an adapter's answer before it is published: only the fields its status allows, frozen, and `failed` with `INVALID_ANSWER` for an answer outside the contract.

## The path of an event

`track(name, properties, options)` runs these steps, and each refusal answers a receipt that is `dropped` at once:

1. After `dispose()`, drop as `disposed`. From inside an adapter call or an `events` listener, drop as `reentrant`.
2. Take the candidates: `options.to`, else a `defaults.to` list, else every destination. When consent closes every candidate, drop as `consent` before anything is validated, sanitized or retained.
3. Validate the properties with the event's definition. A refusal drops the event as `invalid` with the issues.
4. Compose the context: `defaults.context`, then `trace.context()`, then the scope's, then the call's, a later layer winning per key.
5. Sanitize the properties and the context. A `redact` that throws drops the event as `sanitizer-failed`, because privacy outranks delivery.
6. Freeze the `TrackedEvent` with the current identity snapshot and `options.timestamp`, or the clock.
7. Route it. A `defaults.to` function is asked now, once the event exists, and destinations that consent closes are removed. Nothing left drops the event as `not-routed` or `consent`.
8. Deliver the event to the `events` listeners.
9. Enqueue it on each routed lane and answer the receipt, `pending` with one slot per destination.

In the lane, the event waits in the buffer while the destination is idle or failed, or while the entry ahead of it runs its identity steps. Consent is checked again, the planner compares what the provider last applied with the identity the event carries, each step is awaited in order, and then the event is handed off under its deadline and its outcome lands on the receipt. Identity steps are barriers, so an event never overtakes its own identity. Handoffs float, so a slow provider never holds up the event behind it.

## Lanes, identity and consent

Each rule below decides how a lane treats its provider, and each has a cost.

- Every fresh session is seeded blank at the generation current when its lane was built. A sign-out or a user switch made before a destination opens therefore resets it once when it opens, while a plain page load, or one restored sign-in, never does. The cost: an authentication library that flickers user, `null`, user before the destination opens rotates its device id once.
- An identified user continues from what a destination applied only at the same generation. The same user returning at a later generation, after a sign-out or a switch the destination missed while its consent was closed or an identity step was pending, resets that provider first, so none of the earlier session's traits or groups carries over. The cost is one extra reset, never a stale trait or group.
- A gated destination that opens while its consent is open gets `collection(true)` at once, because the application initialized its SDK opted out. One that opens while its consent is closed gets `collection(false)` at once. A destination the `consent` option does not name never receives `collection`. The cost: an application that did not initialize a gated SDK opted out gets a redundant opt-in.
- A consent revocation that lands between two identity steps leaves the provider's applied identity unknown, so the next grant resets it before identifying again. For an anonymous user this starts a new device id.
- A `start()` made while a destination is opening retries it once when that attempt ends. The retry's own notifications cannot schedule another, so a listener that calls `start()` after every failure costs two attempts per call and never a loop.
- When a user switch or a sign-out starts a generation, every lane drops what waits from earlier generations as `identity-changed`. An entry enqueued after its generation was dropped lands `identity-changed` at once, so no path hands off an event whose identity steps were skipped.
- Entries waiting behind a running identity step are held in the same bounded buffer, so an identity call that hangs cannot grow memory without limit.
- A step that throws, rejects or outlasts the timeout leaves the applied identity unknown and skips its event as `identity-failed`, and the next plan starts with a reset. After two consecutive step timeouts, a step and its retry, the lane stalls: it calls no identity step and skips at once each entry whose plan has steps, until one of the timed-out calls settles; the settle plans nothing, and any answered step resets the count. An `identify`, `traits` or `group` step that throws `TraceError` `UNSUPPORTED` is reported and counted as done. A `reset` that fails in any way, `UNSUPPORTED` included, is a failure, because recording a clean state while the SDK still holds the previous user would break release gate 1. So an adapter implements `reset` only when its provider can reset, and the conformance suite fails a `reset` that throws `UNSUPPORTED`.

## Principles

1. Trace normalizes what an application means, not how a provider behaves.
2. An adapter maps one sanitized event onto one provider and nothing more. The core never branches on an adapter's name.
3. The application owns every provider SDK. It initializes, configures and closes it; Trace only calls it.
4. An event keeps the identity, context and time it had when it was accepted.
5. Destinations are independent fan-out. There is no failover between them.
6. Constructing a Trace does nothing. Observing it creates no demand.
7. Trace never throws into its host at runtime. Only misconfiguration throws.
8. No outcome claims more than the provider proves.

## The adapter contract

An adapter is a plain `{ name, open }`, and `open` returns a session: `native` and `track`, and optionally `identify`, `traits`, `group`, `reset`, `collection`, `flush` and `dispose`. The methods a session has say what it can do; nothing else declares a capability. The rules, in short:

1. The factory is cold.
2. The option is `sdk`, typed structurally as `<Name>Like`, and the adapter never imports, initializes or closes its provider.
3. `open` succeeds, or throws `NOT_INITIALIZED` or `UNSUPPORTED` before changing anything.
4. A session implements an identity method only for what its provider can do with it. A per-call provider reads `event.identity` in `track`.
5. Nothing from an event is written to provider globals.
6. `event.id` travels as the dedup id and `event.timestamp` as the event time where the provider takes them, and otherwise `timestamp` is an `unsupported` loss.
7. Context goes under properties, properties winning, and a shadowed context key is an `omitted` loss.
8. What the provider cannot carry is a loss per path, or `skipped: unsupported`. Identity never moves into properties.
9. Answer, do not throw.
10. Evidence is the weakest the SDK proves.
11. `collection` is only for a reversible switch that deletes nothing.
12. A `track` that awaits anything account-dependent compares `context.currentGeneration()` with the event's generation.
13. Members of `<Name>Like` use property syntax.
14. Time comes from `context.now()`, never from the wall clock.
15. What the types enforce is not checked again at runtime.

Each adapter package has one entry point and this layout:

```text
packages/adapters/<name>/
  LICENSE  README.md  package.json  tsconfig.json  tsdown.config.ts
  src/index.ts                     the factory and the public types, nothing else
  src/<name>.ts                    the factory and every helper only it calls
  src/<name>.test.ts               mapping, identity, consent, losses, coldness, native
  src/<name>.contracts.ts          typecheck only, against the real SDK
  src/<name>.sdk.test.ts           the real SDK in Node or jsdom, where it runs there
  src/conformance.test.ts          testAnalyticsAdapter, once per configuration
  src/index.test.ts                expect(Object.keys(api)).toEqual([...])
  src/fake<Sdk>.fixture.ts         in-process fake modelled on a named SDK version
  src/types/<Name>AdapterOptions.ts
  src/types/<Name>Like.ts
  src/utils/constants/<topic>.ts   the provider's names, reserved keys and limits
  src/utils/<helper>.ts            one arrow per file, with its test beside it
```

`testAnalyticsAdapter` runs in each package's `src/conformance.test.ts`, once per configuration that changes behavior. It checks the nine provider-independent rules of the contract over an event and identity updates that a real Trace produced, so an adapter meets frozen, sanitized data exactly as the core hands it over. The event must be answered without throwing and with one of the `TrackResult` shapes, a `reset` must complete, every session it opens is disposed even when an assertion fails, and a rule that does not apply to a session is reported as a skip rather than a pass. It cannot check coldness, mapping or evidence against the provider, so each adapter tests those itself.

| Segment forwarding to a destination Trace also reaches | Documentation only. The topology is the application's choice, and the core cannot see what a provider forwards; the Segment adapter's README warns about double ingestion.                                                 |
| Serverless exit                                        | Documentation only. `flush` and `dispose` are tested; calling them before a handler returns is the application's lifecycle, described in the docs.                                                                         |
| Durable outbox upgrade                                 | Not applicable. Trace keeps no durable outbox, so there is no stored event format to migrate.                                                                                                                              |
| Several tabs or processes sharing an outbox            | Not applicable. There is no shared outbox, so there is nothing to lease.                                                                                                                                                   |
| Impersonation                                          | Documentation only. Trace never identifies implicitly and a user switch resets first; which of actor and subject to send is the application's decision.                                                                    |
| Revenue                                                | Documentation only. Revenue is a typed event in the registry, and a provider's revenue helper is reached through `destination(name).native`.                                                                               |
| Sampling                                               | Not applicable. Trace does not sample, so there is no sampling rule to keep identity calls out of.                                                                                                                         |
